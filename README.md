# Skybyn for Android

Official APK downloads for [Skybyn](https://skybyn.no) — a social app with real-time chat, voice & video calling, a home feed, friends, maps, and more.

This repo hosts the installable build only. Source code lives elsewhere and is private.

## Download

Grab the latest APK from the **[Releases page](https://github.com/CyberBismo/Skybyn-Android/releases/tag/Skybyn-APK)** — it's a single rolling release that always points at the current build.

## Install

1. Download `skybyn.apk` from the release above.
2. Open it on your Android device. If you're prompted to allow installs from this source, allow it for your browser/file manager — this is normal for an app installed outside the Play Store.
3. Open Skybyn and sign in or create an account.

## Features

- Real-time chat with typing/read state, offline history, photo/video/file attachments, and voice messages
- One-to-one voice & video calls with native incoming-call screens
- Home feed — posts, images, likes, comments
- Friends: requests, search, profiles
- Interactive map with location sharing
- Email, Google Sign-In, and Passkey login, with biometric unlock
- Push notifications, multi-language interface, light & dark themes
